# PDF Screenshot Generator

PDF Screenshot Generator is a python tool that creates a pdf document that looks like screenshots of a Python code Editor. In actuality, it generates two PDF documents: one that contains images of the code editor while another contains the output of the code execution. It is useful for creating documentation, tutorials, and presentations but it was solely created so I could generate screenshots of my code that I can print out for my CSC 201 assignment and its corresponding output.

## Why I Created This Tool

I created this tool because I wanted to generate screenshots of my code and its output for my CSC 201 assignment. I found it tedious to take screenshots of my code and its output manually, so I decided to automate the process. Most importantly, I wanted to do assignments for a lot of my coursemates and I wanted to do it in a way that would be efficient and time-saving. I also wanted to create a tool that would be useful for other students who might have the same need.

## How it works

The tool does not do any screenshot process contrary to its name. In summary, it generates two PDF documents: 

1. Code Screenshot PDF: This PDF document contains screenshots of the code editor with syntax highlighting. It uses the `Pygments` library and formats the code with a specific style to make it look like a screenshot of a code editor. It uses HTML and CSS to create the layout and styling of the code editor, and then converts it to a PDF document.

2. Output PDF: This PDF document contains the output of the code execution. It is generated by running the Python code and capturing its output, which is then added to a PDF document.

Instead of taking real screenshots, the tool generates styled PDFs that resemble a code editor and a terminal. For each input Python file, it produces:

* A **code PDF** that looks like a syntax-highlighted editor
* An **output PDF** that looks like a terminal session

This project was originally built to generate printable code and outputs for a CSC 201 assignment, but it can also be used for teaching, documentation, and demonstrations.

## What Problem Does It Solve?

Taking screenshots of code and output manually can be slow and repetitive, especially when working with many files or students.

This tool automates the entire process by:

* Formatting code like a real editor
* Running the code automatically
* Capturing the output
* Packaging everything into clean PDF files

It is especially useful when you need to generate multiple variations of the same assignment with different values.

## What It Does

For each student and each Python file, the tool:

1. Inserts student-specific information into the code (name, matric number, department)
2. Modifies parts of the code dynamically (for example, random efficiency values)
3. Generates a **code PDF** that looks like an editor screenshot
4. Executes the code
5. Captures the real output
6. Generates an **output PDF** that looks like a terminal
7. Bundles everything into a zip file per student

## How It Works

### Code Screenshot PDF

* Uses **Pygments** for syntax highlighting
* Wraps the code in HTML and CSS to mimic an editor layout
* Converts the HTML into a PDF using `wkhtmltopdf`

The result looks like a clean, formatted code editor view.

### Output PDF

* Runs the Python code using a temporary file
* Captures the printed output
* Formats it to look like a terminal session

Each output includes a header like:

```
$ python assignment.py
```

This makes it look like a real command line execution.

## Requirements

Make sure you have the following installed:

* Python 3
* wkhtmltopdf
* 7-Zip (for zipping output files)

### Python Libraries

Install required libraries with:

```bash
pip install pygments
```

## Installation

### 1. Install wkhtmltopdf

Download and install from:

[https://wkhtmltopdf.org/downloads.html](https://wkhtmltopdf.org/downloads.html)

Make sure it is accessible from your system path.

### 2. Install 7-Zip

Download from:

[https://www.7-zip.org/](https://www.7-zip.org/)

Ensure the `7z` command works in your terminal.

### 3. Clone or Download the Project

```bash
git clone https://github.com/fasakinhenry/screenshot-generator.git

```

## Configuration

### students.json

This file contains student details:

```json
[
  {
    "name": "John Doe",
    "mat": "CSC123",
    "dept": "Computer Science"
  }
]
```

Each student will receive their own customized PDFs. In the code, placeholders will be replaced with these details.

### input_code/

Place your Python files here. Example:

```
input_code/
└── CSC201_assignment.py
```

Make sure the code contains the placeholder list:

```python
efficiencies = [0.75, 0.72, 0.78, 0.74, 0.76, 0.73, 0.77]
```

This will be replaced with unique values per student.

## Usage

Run the script:

```bash
python generate.py
```

## Output

* A PDF of the code

```

```

```
CSC201_assignment.pdf
CSC201_assignment_out.pdf
```
